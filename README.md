# ASP.NET Core Study Notes

These are my personal study notes on ASP.NET Core, written while studying .NET web development and working through practical examples. They keep the framework concepts, useful code patterns, and questions I want to revisit in one place.

## Scope and version

The notes focus on modern ASP.NET Core with .NET 10 and C#. ASP.NET Core is the cross-platform web framework in .NET. It is different from classic ASP.NET on .NET Framework, which is outside the main scope of these notes.

The chapters cover HTTP, hosting, configuration, middleware, routing, dependency injection, APIs, server-rendered pages, Blazor, data access, security, testing, and deployment. The examples use a small reading-list service to connect related topics where that makes sense.

.NET 10 is an active long-term support release as of October 2026. Install current patches and check the official support policy when selecting a runtime for a project.

## How to use these notes

Read the chapters in order. The examples start with HTTP and the app entry point, then build toward APIs, user interfaces, data access, and production concerns. Each chapter records the idea behind a feature, the relevant ASP.NET Core APIs, and practical C# examples. The last two chapters gather the code and review questions for a quick revisit.

These are personal learning notes. I update them as I study the framework, test examples, and use the concepts in projects.
